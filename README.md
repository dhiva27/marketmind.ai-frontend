# MarketMind-AI Frontend

This is the Next.js 16 frontend for **MarketMind-AI**, a modern AI assistant web interface built with React, TypeScript, Tailwind CSS, Framer Motion, and Lucide React.

## Features

- **Authentication UI**: Login, Sign Up, Forgot Password
- **Interactive Chat**:
  - Responsive collapsible sidebar
  - New chat creation
  - Chat history management (rename, delete)
  - Simulated streaming responses & markdown code block rendering
  - Regenerate & copy response tools
  - File Uploads (PDF, DOCX, TXT, CSV, PNG, JPG, JPEG up to 20MB)
  - Light/Dark theme switching
- **User Settings & Profile pages**
- **404 Custom Error page**

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.
